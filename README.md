
## 📊 Key Metrics

The following metrics will be calculated based on the available dataset fields.

| Metric | Definition |
|---|---|
| Total Sales | Sum of the sales amount |
| Total Profit | Sales minus applicable costs |
| Profit Margin | Total profit divided by total sales |
| Vendor Contribution | Vendor sales divided by overall sales |
| Inventory Turnover | Calculated using inventory and COGS data |
| Freight Cost | Total freight charges, where available |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ganthisaikiran/Vendor-Sales-Performance-Analysis.git
```

### 2. Navigate to the project folder

```bash
cd Vendor-Sales-Performance-Analysis
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the environment (Windows)

```bash
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```
